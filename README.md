# PREMIUM PULSE

スニーカープレミア価格ウォッチ。掲載する価格は出典・観測日を確認できるデータに限定しています。

## データについて
`data/verified.csv` に検証済みのデータを登録し、`python update.py` で `data/latest.json` を再生成します。価格の自動取得・スクレイピングは行っていません。GitHub Pages公開後、閲覧者は確認済みデータとデモを切り替えられます。

週次更新ワークフローはCSVからの再集計のみであり、価格の自動取得ではありません。


## 価格履歴（2026-11-13 追加）

`price_history.py` は `data/review_candidates.json` の未検証出品情報を `data/price_history.json` に蓄積し、`data/history_summary.json` に件数・同一URLの過去価格との差を保存します。
- 収集時刻・商品URL・掲載価格が同じ記録は重複させない。
- 毎日の収集Workflowに `test_price_history.py` の単体テストと履歴保存を追加。
- URLが同じでもサイズ・状態・出品内容が変わる可能性があり、増減は「個別商品ページの掲載価格差」とのみ扱う。
- 成約価格・転売利益・市場全体の平均価格を推定したものではない。
- その日のAPI収集が成功しない場合は、その週の履歴は追加されない。
- `status.html` では履歴件数と追跡URL数を確認できる。

現在の価格履歴は自動取得の候補データであり、相場ランキングの「確認済みデータ」ではありません。

## 自動収集の実行時刻

Yahoo!ショッピング公式APIを使った未検証の出品候補収集は**毎日07:00 JST**（UTC前日22:00）に設定しています。GitHub Actions側の都合で遅延・実行漏れが起きる場合があります。確認済み価格のCSV再集計は別の週次処理です。

## 新型番の自動発見（2026-11-13）

毎日の収集でYahoo!ショッピングの商品名からNike風の型番候補を抽出し、`data/discovery_queue.json` に未検証候補を保存します。現時点では候補発見のみ自動化しており、確認後に `data/watch_queries.json` へ登録する手順は手動です。公開ランキングに自動掲載しません。手順の詳細は `DISCOVERY_GUIDE.md` を参照してください。

## 商品画像表示（2026-11-13）

Yahoo!ショッピングの商品検索 API v3 が返す `hits/exImage/url`（300px指定）、または `hits/image/medium` / `hits/image/small` の画像URLを利用して、`index.html` / `listings.html` / `models.html` に出品画像を表示します。
- 外部画像は公式APIが返す `https://*.yimg.jp` のURLだけを使い、サーバーへ画像をコピーしません。
- 画像が取得できない場合は「NO IMAGE」を表示。
- 画像は元の出品商品を示す参考資料であり、同じ型番の他のサイズ・状態を保証しません。ショップ出典へのリンクとセットで掲載します。
- 過去の未検証データには画像URLがないため、新しいAPI収集が正常に完了するまで画像なし表示が続きます。
- 出典の表示・画像利用条件、掲載内容の変更や削除依頼に対応できるよう管理します。

## 型番別プロフィール・価格履歴グラフ

`product.html?sku=DZ4137-106` のように型番を指定すると、最新の未確認掲載価格・画像（取得できる場合）・元の出品リンクと、同じ出品URLの価格観測履歴を確認できます。
- サイト内の出品一覧、型番検索、トップページから各プロフィールへリンク。
- グラフは同一商品URL単位。サイズ・状態が混じる型番全体の「成約相場」や中央値と誤認させない。
- 異なる観測日時が2つ未満のときはグラフを表示せずデータ不足を案内。
- 公開前に商品仕様や画像利用条件の再確認、スマートフォン実機テストを推奨。

## 追跡型番の拡大とサイズ別比較（2026-11-13）

- 毎日の検索対象を2→12型番に拡大。これらは出品情報の検索対象であり、正式な型番と商品同一性の検証を意味しません。
- 発見キーワードを3→8種類へ拡大。新規候補は従来どおり確認待ち（`data/discovery_queue.json`）で、追跡対象へ無制限には自動追加しません。
- `collect_yahoo.py` は商品名に明示された `xxcm`／`xxセンチ` のみ `size_cm_hint` として抽出。明記されないサイズは `null`。
- `listings.html` でサイズ絞り込み、`product.html?sku=...` でサイズ×状態別の出品候補最安価格を参考表示。いずれも**販売元の商品名・APIヒント由来で未検証**。未検証の情報を成約相場とは呼びません。
- 次のAPI定期収集が完了するまでは、画面に保存済みの旧データ（2型番分）が表示されます。設定型番数は `status.html` で確認できます。
- API利用回数が増えるため、連続失敗や利用制限があれば検索件数・頻度を調整します。

## 複数サイト比較と値下がり発見（2026-11-13）

- `compare.html`：型番、サイズ、状態、出典サイト別の出品価格候補一覧。Yahoo!と楽天のAPIが返す未検証商品を明示して表示。
- `drops.html`：同一商品のURLごとに直近2回の価格が下がった場合だけ値下がり候補として一覧表示。モデル全体の成約相場、利益、売れ行きの判定ではありません。
- `collect_rakuten.py`：楽天市場商品検索API（2026-07-01）を用いた任意の追加データソース。利用者が `RAKUTEN_APP_ID` と `RAKUTEN_ACCESS_KEY` をGitHub Actions secretsに登録した場合のみ収集。未設定時は現状を維持。
- 初期 `data/rakuten_candidates.json` は `status: not_configured`、**0件**。未接続状態を実際のデータとして装いません。
- 利用条件・具体的な設定は `RAKUTEN_SETUP.md` を参照。出品価格と成約価格は明確に区別します。
